# Speech conferences 2026 — ICASSP (a titles-only theme map)

**Live:** https://mehtama1234.github.io/speech-conferences-2026/

A first, honest map of **ICASSP 2026** (Barcelona) built from **titles only** — because
that is what's public right now: ICASSP publishes through IEEE Xplore, which gates
abstracts (only ~18% are open). So this is a reliable read of *what topics are present and
how much*, not the per-paper problem/approach analysis that needs abstracts.

Key finding: ICASSP is "Acoustics, **Speech**, and Signal Processing" — a *broad* conference.
Speech is only ~15% of it (image & video is larger). Within the speech slice, ASR leads,
then music/sound-events, enhancement, self-supervised, speaker-verification/anti-spoofing.

A full per-paper analysis, and **Interspeech 2026** (Sydney, Sept 28–Oct 1), will follow when
open proceedings publish. Pipeline: `ingest_icassp.py -> mine_themes.py -> build_page.py`.
